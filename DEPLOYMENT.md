# Render monolith deployment

This repository deploys as one Docker web service:

```text
Browser → Render Web Service → FastAPI
                              ├── /api/* REST endpoints
                              └── React/Vite build + SPA routes
```

There is no separate frontend service in production. FastAPI serves the compiled React app from `/app/frontend/dist`, and the frontend calls the API on the same origin at `/api`.

## Deploy with Render Blueprint

1. Push the repository to GitHub.
2. In Render, choose **New → Blueprint**.
3. Select `hemanthh35/smart_carbon_analytic_platform`.
4. Render detects the root `render.yaml`; confirm the `smart-carbon-analytics` web service.
5. Deploy. The first build installs TensorFlow and can take several minutes.
6. Open the generated `onrender.com` URL and check `/health`.

The Blueprint uses a persistent disk at `/var/data` for SQLite, reports, uploads, and logs. Persistent disks are intended for paid Render services. For a disposable demo, remove the `disk` block and use an external database before storing real data.

## Local monolith test with Docker

```powershell
docker build -t smart-carbon-analytics .
docker run --rm -p 10000:10000 `
  -e SECRET_KEY="local-development-secret-change-me" `
  -e DATABASE_URL="sqlite:////var/data/backend.db" `
  smart-carbon-analytics
```

Open `http://localhost:10000` and verify `http://localhost:10000/health`.

## Local split development

Run the backend from `backend/` on port 8000 and the frontend from `frontend/` on port 5173. Vite proxies `/api` to FastAPI without removing the `/api` prefix.

```powershell
# terminal 1
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# terminal 2
cd frontend
npm install
npm run dev
```

## Render environment notes

- `SECRET_KEY` is generated by Render through `render.yaml`; do not commit a real secret.
- `PORT` is supplied by Render and the Docker command binds to `0.0.0.0`.
- `/health` is the configured Render health check.
- The model and scaler are copied from `backend/app/ai/` into the image.
- The dataset is copied into `/app/datasets/`, which matches the backend dataset lookup.
